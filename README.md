## 🧩 Ejercicio asignado

### Pokémon

El trabajo consiste en el diseño y desarrollo de una **base de datos relacionada con el universo Pokémon**, contemplando diferentes aspectos como especies, juegos, ubicaciones, capturas, evoluciones y demás relaciones necesarias para representar correctamente el dominio planteado.

---

## 📚 Trabajo Final — Bases de Datos

A lo largo del proyecto se desarrollan las distintas etapas del diseño de una base de datos:

- Modelo Conceptual
- Modelo Relacional
- Normalización
- Implementación de la base de datos
- Consultas y operaciones sobre los datos
